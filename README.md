# ORUP Assurances

Custom corporate website developed for an insurance brokerage and financial services company based in the Paris region. Built as a high-performance static website inspired by a premium WordPress template, with a strong focus on branding, responsiveness, and search engine optimization.

🔗 **Live Demo:** https://redabensaad.github.io/orup/

## ✨ Key Features

* **Corporate Showcase Website:** Designed to present insurance and financial consulting services.
* **Custom Branding:** Tailored visual identity aligned with the company's business sector.
* **Responsive Design:** Optimized experience across desktop, tablet, and mobile devices.
* **SEO-Oriented Development:** Structured content and optimization techniques to improve search visibility.
* **Premium-Inspired UI:** Adaptation of a premium WordPress design into a custom static website.
* **Fast & Lightweight:** Fully static architecture without backend dependencies.

## 🎯 Project Goals

* Establish a professional online presence for an insurance brokerage company.
* Showcase services, expertise, and company information.
* Strengthen brand identity through custom design elements.
* Improve online visibility through SEO best practices.
* Deliver a fast, secure, and maintainable website solution.
